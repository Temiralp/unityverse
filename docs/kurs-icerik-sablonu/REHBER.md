# Kurs İçeriği Word Şablonu — 1 Sayfalık Rehber

Kurs içeriklerini admin paneline **tek tıkla** aktarabilmemiz için gönderdiğiniz Word dosyasında
yalnızca üç Word stilini kullanmanız yeterlidir. Örnek: `Kurs_Icerik_Sablonu.docx` (bu klasörde).

## Kurallar
1. **Dosya türü:** `.docx` gönderin (PDF değil). PDF'ten yapı okunamaz.
2. **Bölüm başlığı → "Başlık 1"** stili. Örnek: `1. Eğitim Amacı`, `2. Eğitim Yaklaşımı`, `4. Ders Müfredatı`.
3. **Modül / hafta başlığı → "Başlık 2"** stili (yalnızca "Ders Müfredatı" bölümünün altında).
   Örnek: `1. Siber Güvenliğe Giriş`, `3. Hafta – Uygulama`.
4. **Ders maddeleri → "Madde İşareti"** (bullet) stili. Elle "•" veya "-" yazmayın; Word'ün madde işaretini kullanın.
5. Açıklama metinleri **Normal** stilde kalsın. Tablolar desteklenir; görseller (v1) aktarılmaz.

## Word'de stil nasıl uygulanır?
Satırı seçin → **Giriş** sekmesi → **Stiller** → `Başlık 1` / `Başlık 2` / `Madde İşareti`.
(Mac: Home → Styles pane.)

## Bölümler siteye nasıl düşer?
| Word'deki bölüm | Sitedeki tab |
|---|---|
| "Ders Müfredatı" / "Program" / "Modüller" altındaki Başlık 2'ler | **Ders İçerikleri** (açılır-kapanır modül listesi) |
| Müfredattan önceki bölümler (Amaç, Yaklaşım…) | **Eğitime İlk Bakış** |
| "Kazanımlar" / "Neden" / "Hedef" başlıklı bölüm | **Neden Bu Eğitim** |
| Diğer bölümler | Önizlemede "eşleşmeyen" olarak gösterilir; admin karar verir |

Stil kullanılmamış bir dosya da işlenir (metin desenlerinden tahmin edilir), ancak önizlemede
kontrol gerekir. Stil kullanılmışsa sonuç birebirdir.
